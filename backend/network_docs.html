线路目录与测速 API

公开接口，无需登录。所有地址固定在服务端，不接受用户指定目标 URL。

GET /cm/network/lines

默认返回主站及三个 CDN 镜像，并发测量服务器到各线路探针的 HTTPS 请求。结果共用 60 秒缓存，首次请求最多等待约 5 秒；同时发起的其他请求返回已有缓存或 measuring=true 的目录。测量时不携带用户登录态。

?measure=0 仅取目录，不发起测速。measure=1 使用缓存或执行测速，不能强制绕过缓存。响应设置 Cache-Control: no-store；这是浏览器/CDN 缓存策略，与服务器内部 60 秒缓存不同。

{
  "perspective": "server", "measuredAt": 1793450000,
  "cacheTtlSeconds": 60, "cached": false, "measuring": false,
  "lines": [{
    "id": "main", "name": "主站", "origin": "https://music.20110208.xyz",
    "appUrl": "https://music.20110208.xyz/app/",
    "probeUrl": "https://music.20110208.xyz/cm/network/probe",
    "result": {"status": "ok", "available": true, "httpStatus": 200, "latencyMs": 320.5}
  }]
}

示例仅展示一条线路，实际返回全部四条。measuredAt 为 Unix 秒；未测速为 null。latencyMs 为毫秒，失败时可能为 null，不能当成零延迟。measure=0 的目录不含 result。

status说明
okHTTP 200 且返回正确服务标识
http_error非成功 HTTP 状态，见 httpStatus
invalid_response不是预期的探针 JSON，或数据格式错误
unreachable连接、DNS、TLS 或读取失败
timeout未在本次总等待时限内完成
busy探测槽位繁忙，本条未执行

GET /cm/network/probe

轻量探针，返回 {"service":"CurrentMusic","ok":true,"now":1793450000}，支持跨域读取并禁止缓存。浏览器可附随机 t 查询参数避免中间缓存。

const start = performance.now();
const response = await fetch(origin + '/cm/network/probe?t=' + Date.now(), {
  cache: 'no-store', credentials: 'omit', signal: controller.signal
});
const data = await response.json();
if (response.ok && data.ok && data.service === 'CurrentMusic') {
  const latencyMs = performance.now() - start;
}

controller 为调用方创建的 AbortController，请设置超时并在完成后清理计时器。公开接口仍受服务端 IP 限流约束。

测量口径

perspective=server 的结果来自服务器网络；浏览器本地测速来自用户设备。两者不可混用，均不是 TCPing、带宽或全业务可用性保证。本地页面每条线路测两次，只在两次均成功的线路中标记耗时最低者，不自动跳转。
