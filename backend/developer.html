四步接入

拿到 client_id 后，按下面四步就能跑通「通行证登录」。

  1. 把用户送到授权页

    GET /cm/passport/authorize?client_id=…&redirect_uri=…&scope=…&state=…&code_challenge=…&code_challenge_method=S256

  2. 回调里拿 code

    用户在通行证页面点「同意」后跳回你登记的回调地址，带上 ?code=…&state=…（code 60 秒、只能用一次）。

  3. 用 code 换令牌

    服务端 POST /cm/passport/token，带 code_verifier（公开客户端）或 client_secret（机密客户端）。

  4. 拿用户信息

    GET /cm/passport/userinfo 带 Authorization: Bearer cs_at_…，按 scope 返回昵称/头像/脱敏邮箱等。
