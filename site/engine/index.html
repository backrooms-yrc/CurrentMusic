CURRENTMUSIC ENGINE开源音乐后端

流声引擎

不同的播放器，共用一套音乐服务。

流声屿 Web 和社区客户端 CurrentMusicX 通过同一引擎获取音乐、歌词与账户服务。你也可以接入 API，或在自己的服务器上运行引擎。

开始接入 ↗ 自托管指南 ↗

01 工作方式

播放器负责体验，引擎管理服务。

01 账户与音乐库
提供账户和会话，管理收藏、歌单和最近播放。客户端可以按各自的方式呈现同一份音乐库。
02 搜索、音源与歌词
对接音乐上游，提供搜索、歌曲详情和音源解析，并向客户端返回统一的歌词格式。
03 一起听
为听歌房间维护共享队列和播放状态，让不同设备可以一起听同一首歌。

02 开发接入

从一次请求开始。

先用公开的健康检查确认实例可达，再按文档接入搜索、歌词和需要登录的播放接口。

03 自托管

把引擎运行在自己的服务器上。

引擎使用 Python 和 SQLite。公开仓库提供后端源码、环境配置示例和部署模板。音乐功能可接入独立的网易云 API 实例。
