项目简介

CurrentMusic 是什么，以及它想做成什么样。

CurrentMusic 是一个免费畅听网易云音乐 SVIP 曲目的音乐社区。 它提供 Web 网页端、Android 客户端与开放 API，支持多设备流转音乐资产， 并鼓励社区开发者参与生态建设。

项目的出发点很直接：让听歌这件事不被会员门槛切断。你可以在浏览器里直接打开网页收听， 也可以安装 Android 客户端获得更完整的体验；登录同一账号后，歌单、收藏与播放进度等 音乐资产会在多台设备之间流转，不必反复整理。

与此同时，CurrentMusic 把能力通过开放 API 暴露出来。任何开发者都可以阅读文档、 免费接入，把自己的想法做成新的客户端或小工具，让整个生态由社区一起长出来。

功能亮点

  • 免费畅听 SVIP 曲目 无需开通会员，直接收听原本需要会员权限的曲目。
  • 多端覆盖 Web 网页端、Android 客户端（CurrentMusicX / 概念版）按需选择。
  • 音乐资产流转 登录后歌单、收藏与播放数据在多设备间同步。
  • 开放 API 与社区生态 通过 CurrentStation 控制台免费接入，文档完善，便于二次开发。

适用人群

  • 想免费收听网易云音乐 SVIP 曲目的普通听众
  • 希望在手机与电脑之间无缝续听的用户
  • 偏好网页端、不愿安装额外软件的用户
  • 想把音乐能力接入自己应用的开发者

项目愿景

把音乐能力开放出来，让客户端、工具与玩法由社区共同创造； 在合规与尊重版权方的前提下，做一个长期可用的音乐社区。

使用提示

概念版基于 Android WebView，在部分老设备上可能出现显示异常、版式错乱、 性能降低等问题；追求稳定体验时请选择 CurrentMusicX 或 Web 网页端。
