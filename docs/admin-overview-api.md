# 管理台用户来源统计

`GET /admin/overview` 需要管理员 Bearer 令牌。返回的 `sourceCounts` 包含 `web`（Web 端）、`x`（CurrentMusicX）和 `other`（其他）的账号数。三项均为整数，合计等于同一响应中的 `users`。

每个账号按最近一次成功登录或注册归类。退出登录保留最近一次归类，内部账号不参与统计。当前 X 侧版本根据登录请求中的 `app` 平台、设备标签和 OkHttp 标识识别，也支持显式的 `x` 平台标识。

首次升级时使用旧账号最近一条仍保留的会话补算。缺少会话或仅有通用客户端标识的账号归入 `other`，下次成功登录后更新。
