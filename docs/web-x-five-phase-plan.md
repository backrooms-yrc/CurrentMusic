# CurrentMusic Web 对齐 X 的五阶段迭代

冻结基准为 CurrentMusicX [v1.3.6](https://github.com/bileizhen/CurrentMusicX/releases/tag/v1.3.6)（`d5eacfce549d4582a9f8a5be5a713199157514df`），Web 对照起点为 `a2876df`。矩阵中 X 源码路径以该版本的 `app/src/main/java/io/github/currencortex/music/` 为根，`AndroidManifest.xml` 位于 `app/src/main/`。

## 计分

[验收矩阵](web-x-feature-matrix.csv)记录 175 个独立的用户任务。实现与实测分别登记。只统计从正常 Web 或 PWA 入口完成任务、权限和关键异常恢复的实机通过项。接口或模拟测试单独通过，仍保留为待验收。分母包含原生平台缺口，目标为 **167/175（95.43%）**。同一 X 版本的漏项需要补录并重算最低通过数，后续版本另记差异。

核心流程运行于 Android Chrome、iOS Safari、桌面 Chrome/Edge、Firefox 和 macOS Safari。扩展能力按矩阵登记的适用平台实测，每个平台公布缺项。锁屏、蓝牙、扫码、目录授权、离线及设备输出使用真实设备验证。

## 已实施增量与验证边界

- 账户和播放连续性已接入正常 Web 路径。开始点播时保留原队列，支持队列编辑、恢复位置、歌单定位及定时关闭。已保存账户按 API 服务隔离，播放存档不保存会话或媒体播放地址。
- 增补估算逐字开关和手机歌词视图自动隐藏播放控制。当前支持网易云队列存档。无来源归属的旧存档仅在当前服务只有一个已保存账号时迁移。
- 第二阶段的服务器音源目录、选择、移除及取链已接入 Web。使用当前 HTTPS 服务器和账户，所有目录和取链请求拒绝重定向。切换客户端入口后须在同一服务器和账号下才能使用已导入项。
- Web 已有 QQ 音乐入口、扫码会话、分类搜索及热搜联想、曲库详情、我的歌单、红心入口及热门和最新评论。播放和歌词使用共享播放器，QQ 曲目绕过网易云专属读写。当前采用兼容接口提供的三档音质及自动档，QQ 会话保存在当前浏览器标签页。QQ 首页推荐、漫游、完整音质、真实逐字与报告能力仍待补齐。
- 播放器支持查找、预览和保存候选歌词，按曲目调整偏移，及 FIA/LRC 原始时间轴导出。已验证标准 LRC、FIA、TTML、VTT、YRC、明文 QRC 和明文 KRC 的基本导入。加密 KRC、复杂 TTML/FIA 角色和自适应时间轴对齐仍待补齐。
- 网易云听歌足迹支持每周排行的三种唱片墙模板与 PNG 导出。其他周期与本机来源仍待接入。
- 十段 Web Audio 均衡器已接入播放器。旧五段配置保持原来的滤波行为，主动修改后才保存并应用十段设置。
- `tools/test-web-playback-parity.cjs` 使用模拟账号与真实可解码音频验证队列、定时暂停及恢复 Playwright 流程。发布覆盖率仍需真实设备、账户与上游功能逐项确认。当前工作环境未连接 Android 测试设备，也未获得可用于网易云和 QQ 写入的测试账号。
- 线上的 QQ 登录通道查询返回 `200`。匿名搜索首轮返回 `502`，重试公网和本机入口均返回 `200`。使用有效测试会话复核真实扫码与媒体播放后方可计为通过。
