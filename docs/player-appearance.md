# 播放页外观与频谱

设置 → 外观 → 播放页封面形状，可选择「圆角方形（MD3）」或「圆形」。默认圆角方形，
使用 20px 圆角；设置保存在当前设备的 localStorage（`cm.coverShape`），立即生效，
适用于 Material 3、简约玻璃与 CurrentMusicX 全部界面风格及浅色/深色主题。

矮屏使用紧凑频谱与较小封面，保留律动和播放控制。桌面播放页保留封面/控制区与歌词双栏。歌词区隐藏原生滚动条，仍支持滚轮、触摸与自动跟随。

播放页封面按实际剩余高度缩放并保留方形比例，播放按钮和进度条优先占位。
歌名最多显示两行，桌面悬停可查看完整标题；歌手、专辑与统计信息限制在栏内。
切歌、字体放大、横竖屏切换与窗口缩小时自动重新布局；极矮窗口可滚动访问操作区。
这些规则适用于原有界面风格，手表继续使用紧凑网格布局。

频谱使用实际音频的 Web Audio 数据。播放器在真实点击、触摸结束或键盘手势中创建和恢复
AudioContext，再在音源 CORS 校验通过后连接媒体分析器，避免等异步加载完才创建导致上下文被
自动播放策略挂起。切歌复用已解锁的上下文；CORS 回退时保留上下文，返回前台或后续手势时
尝试恢复 suspended/interrupted 状态。上下文无法恢复时仍保留普通播放，并允许之后的真实手势
重新启用频谱；不支持 CORS 的音源继续使用普通播放和静默基线，不生成假波形。

频谱颜色跟随配色方案：动态取色时使用当前封面提取出的强调色，切歌后立即刷新 Canvas
渐变；选择固定配色时改用该方案主色。快速连续切歌时，仅当前歌曲的取色结果可以生效。

浏览器策略依据：[Chrome 自动播放与 Web Audio](https://developer.chrome.com/blog/autoplay/)、
[WebKit 用户手势与媒体播放](https://webkit.org/blog/6784/new-video-policies-for-ios/)。
系统启用「减少动态效果」时，频谱继续按无障碍偏好显示静态基线。

## 翱翔鸟Music

在「设置 → 外观 → 界面风格」中选择「翱翔鸟Music」。桌面播放页并排显示封面与歌词，手机通过歌词按钮切换视图。选用「跟随系统」时保持浅色，也可在设置中指定深色。

翱翔鸟Music 的音量滑块记住该主题的音量。切回其他主题时恢复进入前的播放音量，正在播放的曲目会继续播放。
