# 协作与合并规则

CurrentMusic 现在是包含后端、Web、Android、Windows 与部署文档的统一公开仓库，默认分支 main。贡献步骤与验证要求以 [CONTRIBUTING.md](../CONTRIBUTING.md) 为准。

## 权限与 CI

- 成员通过分支和 PR 提交改动；维护者可按已授权任务推送。
- CI 运行后端完整测试（临时数据库）、文档/公开导出回归、前端构建及产物一致性、敏感文件与 Gitleaks 扫描。
- Windows 目录变化运行 Windows 原生客户端工作流；尚未运行的检查不能声称通过。
- `main 直推检查` 仅报告来源，不更改 Git 引用。不要用工作流强推回退他人工作；平台分支保护由维护者按协作需要配置。
- 可选 AI 审查的凭据由公开库自己的 Actions secrets 管理，不从私有仓库复制。

## 部署与发版

前端构建后先部署资源，再切换 index.html；后端有行为变化时重启对应服务并验证。完整步骤和本机授权由本地 AGENTS.md 规定，该文件永远不入库。

Android 发版需明确的发布任务：同步版本号、签名构建、服务器更新源、公开仓库标签与 Release。日常文档和后端改动无需制造 APK 发版。APK、MSI 与签名密钥不作为源码提交。

历史私有 Git 库继续保密。禁止将其历史 merge、mirror 或强推至公开库；公开 main 是日后开发的上游。CurrentMusicX 不随本仓库自动提交或发布。
